# CO'Esprit — Maquette Angular

Prototype navigable (données fake) pour valider l’UX avant Convertigo (`coesprit_fe`).

## Design system

Réutilise les tokens / composants CSS de `maquette_admin_lcnc` (charte Urssaf Acoss : bleu `#1A428A`, Montserrat / Roboto, sidebar, fields, boutons).

## Lancer

```bash
cd maquette_coesprit
npm start
```

Ouvre http://localhost:4200
